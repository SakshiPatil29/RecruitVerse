Title
: RecruitVerse - AI Resume Screening & Candidate Ranking System
Platform
: Python, Streamlit, Sentence-Transformers,
NLP, pandas, FastAPI, PostgreSQL
Duration : 1 Month
Description
: RecruitVerse is an AI-powered Applicant Tracking System (ATS) that automates resume screening and candidate
ranking. Recruiters upload a job description and resumes (PDF, DOCX, or TXT), and the system extracts skills,
experience, education, and projects into structured data. It ranks candidates using Natural Language Processing
(NLP) and Machine Learning. Semantic similarity is computed using Sentence-Transformers embeddings and
cosine similarity, enabling meaning-based matching instead of keyword matching. The final score is a weighted
combination of skill match (50%), semantic similarity (30%), and experience relevance (20%), with an explainable
breakdown of matched, missing, and additional skills. The system also generates candidate summaries, hiring
recommendations, interview questions, and semantic resume search. Built with Python and Streamlit, it provides a
recruiter-friendly interface for faster, consistent, and transparent hiring.
